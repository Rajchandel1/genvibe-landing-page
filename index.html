01 / Setup

Install once.
Then just use vibe.

You only need Node.js and npm. Node.js 20+ is recommended. After that, setup is basically three steps.

1

Install GenVibe

Run this once. After installation, the vibe command will be available from your terminal.

npm install -g genvibe
2

Log in to Qwen once

Run vibe chat. Qwen will open in your browser. Log in once. If Qwen accepts a disposable email, you can use Temp Mail ↗.

vibe chat
3

Start working

GenVibe normally keeps using the same browser session, so you don’t have to log in every time. If the session expires or browser data is cleared, Qwen may ask you to log in again.

vibe update "your change"
Quick tip: open the terminal inside the project folder you want to work on. For a brand-new project, use an empty folder. For updates, run GenVibe inside your existing project.
02 / Commands

These are the commands
you’ll actually use.

You don’t need to memorize a giant command list. Start with these and you’re good.

vibe "build me..."
Create a new project from a prompt. Run it inside an empty folder.
create
vibe update "<request>"
Tell GenVibe what you want changed in your existing project.
update
vibe dry-run "<request>"
See the planned change without writing anything to your project.
preview
vibe ask "<question>"
Ask about your project without changing any file. Great for debugging and understanding code.
read-only
vibe chat
Open the interactive console and keep working in the same project.
interactive
vibe undo
Go back to the latest safe snapshot if you don’t like the last update.
undo
vibe new-chat
Start a fresh Qwen conversation when you want a clean context.
reset
Inside vibe chat

Use slash commands

↳/update <request>
↳/ask <question>
↳/dry-run <request>
↳/fix <error>
↳/undo
↳/new-chat
↳/exit
Prompting

Talk normally.

You don’t need a “perfect AI prompt.” Just explain what you want. Mention the page, component, bug, feature, or design change if you know it.

vibe update "make the pricing cards responsive and keep the current design"
03 / Your normal flow

Open project.
Say what you want. Done.

This is the flow you’ll use most of the time.

01 Open the folder

Start the terminal inside your project.

02 Describe the change

Use vibe update or vibe chat.

03 Preview if you want

Use dry-run before a change when you want extra confidence.

04 Let GenVibe work

It updates the relevant project files and runs its verification flow.

05 Undo if needed

If you don’t like the last update, use vibe undo.
